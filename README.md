# Requirements Grilling Skill

Interview a user until a plan or design is specific enough to implement safely.

The skill asks focused questions, challenges ambiguity, and records decisions without making external changes.

## Attribution

For a quick start, check out Matt Pocock's [skills repository][mattpocock-skills]
first. This independent implementation exists because a comparison found
substantial overlap and identified reusable generic workflows for this
collection.

The round-based interview format is adapted from Matt Pocock's
[`grilling`][grilling] skill (MIT licence); see
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
